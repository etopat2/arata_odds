# Arata Odds brand

The identity pairs a geometric A with an ascending probability path in its negative space. The symbol represents analysis and measured progress. The live wordmark is **Arata Odds**, set in the app's system sans-serif with tight letter spacing; Odds uses the mint accent.

- Primary logo: `public/brand/arata-mark.png`, transparent 1254 × 1254 PNG.
- Midnight navy: `#0A0E1A` — application background.
- Probability mint: `#00E5A0` — logo, selected actions and Arata chart line.
- Soft white: `#F1F6FC` — wordmark and headings.
- Muted slate: `#8B9BB1` — supporting text.
- External model blue: `#72AAFF`; blended model amber: `#FFBD69`.

Keep the symbol's proportions and transparency. Use at least 32 CSS pixels for the standalone application symbol. Preserve clear space of approximately one quarter of the symbol height. Do not stretch it, add a glow, place it over busy imagery or use its accent as a promise of winning. The application uses it in desktop navigation, the mobile header, favicon, install manifest and offline screen. Manifest icons are ordinary icons; this version does not claim a separate maskable icon.
